# Bitácora de Sesión: P-108 Reglas de Arquitectura en CI

**Fecha:** 2026-10-06
**Herramienta:** Antigravity

## Objetivos

Implementar `dependency-cruiser` para garantizar que no se rompan las reglas de la arquitectura limpia, integrándolo en el pipeline de validación continua (CI).

## Acciones realizadas

1. **Instalación:** Se instaló `dependency-cruiser` como dependencia de desarrollo.
2. **Configuración:** Se creó el archivo `.dependency-cruiser.cjs` definiendo las reglas de la arquitectura estipuladas en el plan:
   - `domain` es puro.
   - `application` solo depende de `domain` y `shared`.
   - `infrastructure` depende de `application` y `domain`.
   - `presentation` no puede depender directamente de `infrastructure`.
3. **Prueba de violación:** Se probó inyectando intencionadamente una dependencia de infraestructura en la capa de dominio. `dependency-cruiser` bloqueó correctamente la ejecución. Se procedió a revertir este cambio.
4. **Script npm:** Se añadió `npm run arch:check` al script de validación `npm run verify`, el cual ejecuta el linting, chequeo de tipos, pruebas unitarias y ahora, la validación de arquitectura.
