# Bitácora de Sesión: P-107 Store Reactivo Global (Jotai)

**Fecha:** 2026-10-06
**Herramienta:** Antigravity

## Objetivos

Implementar la tarea **P-107** creando un almacén global reactivo y atómico para los datos del restaurante.

## Acciones realizadas

1. **Gestor de estado:** Se instaló `jotai`, elegido por su eficiencia con re-renderizados atómicos y simplicidad, para actuar como única fuente de verdad reactiva en la UI.
2. **Store central:** Se creó el archivo `src/app/store.ts` exponiendo el átomo `restaurantAtom` (`atom<Restaurant | null>(null)`).
3. **Reglas:** La creación de este único punto de estado garantiza que cualquier componente a lo largo del árbol que lo necesite siempre obtenga el mismo objeto inmutable validado, sin _prop-drilling_ y tipado con la entidad estricta `Restaurant` proveniente de la capa de dominio.
4. **Verificación:** `npm run verify` se ejecutó con éxito confirmando que no hay conflictos de tipos ni lint.
