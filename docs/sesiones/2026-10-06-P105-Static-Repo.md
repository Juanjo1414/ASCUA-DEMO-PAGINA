## Objetivos

Implementar la tarea **P-105 — Repositorio de contenido estático** (infrastructure/content/StaticJsonRestaurantRepository.ts).

## Acciones realizadas

1. **`StaticJsonRestaurantRepository`:** Se implementó la clase que cumple con la interfaz `RestaurantRepository` para la consulta de datos del restaurante.
2. **Validación:** Se agregó una capa de seguridad con la expresión regular `RESTAURANT_SLUG_REGEX` que rechaza slugs inválidos o con _path traversal_ inmediatamente, sin realizar la consulta HTTP. 3. **Pruebas:** Se implementaron pruebas unitarias (`tests/unit/infrastructure/content/StaticJsonRestaurantRepository.test.ts`) donde se hizo "mock" de `fetch` y se cubrieron casos de fallo HTTP, error de validación de JSON con Zod, slugs inválidos y el "happy path".
4. **Verificación:** Se corrigió un error en el mock de la prueba relacionado al arreglo de categorías, confirmando el correcto funcionamiento con `npm run test` y `npm run verify`. Todo pasa correctamente y no se identificaron problemas con lint o TypeScript.
